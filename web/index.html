lastwords symbolizer

Drop the firmware .elf and a lastwords export (the .bin, or a UART log with the hex between ---- export ---- markers, or the text lw_print() wrote). The page decodes the records and maps pc, lr, mepc, ra and return addresses on the saved stack to function and file:line. Everything runs in this tab; nothing is uploaded.
